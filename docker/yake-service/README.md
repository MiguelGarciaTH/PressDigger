# YAKE Keyword Extraction Service

**Port:** `8002`  
**Base Image:** `python:3.11-slim`  
**Framework:** FastAPI + Uvicorn

## Description

An automatic keyword extraction microservice that identifies the most relevant keywords and key-phrases from article text. In the ScribeRef pipeline, this service is called by the **scribe-news-embeddings-processor** during article ingestion — after an article summary is generated by OpenAI, YAKE extracts the top keywords from the summary. These keywords are stored in the `keyword` and `article_keyword_score` tables, enabling keyword-based article browsing, filtering, and public collection generation.

## Model / Algorithm

**[YAKE! (Yet Another Keyword Extractor)](https://github.com/LIAAD/yake)**

| Property              | Value                                    |
|-----------------------|------------------------------------------|
| Type                  | Unsupervised, statistical                |
| Approach              | Graph-based with statistical features    |
| Training required     | None (language-agnostic by design)       |
| License               | GPL-3.0                                  |
| Developed by          | LIAAD — INESC TEC, University of Porto   |

### Why YAKE?

- **No training data required** — YAKE is fully unsupervised and works out-of-the-box on any language without pre-trained models or labeled data, making it ideal for processing Portuguese news text.
- **Portuguese origin** — Developed at INESC TEC / University of Porto, YAKE was designed and tested with Portuguese text as a primary use case, ensuring excellent performance on the ScribeRef corpus.
- **Lightweight and fast** — Unlike transformer-based keyword extractors, YAKE uses statistical features (term frequency, position, relatedness) to rank candidates. This makes it extremely fast with minimal resource usage — critical when processing thousands of articles.
- **Multi-word keyword support** — YAKE supports n-gram extraction (configured with `max_ngram_size=2`), capturing meaningful multi-word expressions like "primeiro-ministro" or "António Costa".
- **Built-in deduplication** — The `deduplication_threshold` parameter prevents near-duplicate keywords (e.g., "Costa" and "António Costa") from appearing in the results.

## Configuration

The service applies a **relevance score filter** (`score < 0.3`), discarding keywords with low relevance. In YAKE, lower scores indicate higher relevance.

| Parameter                  | Default | Description                              |
|----------------------------|---------|------------------------------------------|
| `language`                 | `"pt"`  | Language code                            |
| `max_keywords`             | `10`    | Maximum keywords to return               |
| `max_ngram_size`           | `2`     | Maximum words per key-phrase             |
| `deduplication_threshold`  | `0.7`   | Similarity threshold for deduplication   |

## API Endpoints

| Method | Path       | Description               |
|--------|------------|---------------------------|
| GET    | `/health`  | Health check              |
| POST   | `/extract` | Extract keywords from text |

### POST `/extract`

**Request:**
```json
{
  "text": "António Costa demitiu-se do cargo de primeiro-ministro após a operação Influencer...",
  "language": "pt",
  "max_keywords": 5,
  "max_ngram_size": 2
}
```

**Response:**
```json
{
  "keywords": [
    { "keyword": "António Costa", "score": 0.001234 },
    { "keyword": "primeiro-ministro", "score": 0.005678 },
    { "keyword": "operação Influencer", "score": 0.012345 }
  ]
}
```

Keywords are sorted by score ascending (most relevant first).
