# PressDigger Datasets

This folder contains Parquet exports of the PressDigger database, generated by [`db/scripts/export-to-parquet.py`](../db/scripts/export-to-parquet.py).

## How to Generate

```bash
cd db/scripts
python3 -m venv .venv && source .venv/bin/activate
pip install pandas pyarrow psycopg2-binary sqlalchemy

# Load DB credentials from the project .env, then run:
set -a && source ../../.env && set +a
PARQUET_OUTPUT_DIR=../../datasets python export-to-parquet.py
```

## Files

### `article.parquet`

One row per news article crawled from [Arquivo.pt](https://arquivo.pt).

| Column | Type | Description |
|---|---|---|
| `id` | int | Primary key |
| `site_id` | int | Foreign key → `site` table (news outlet) |
| `author_id` | int | Foreign key → `author` table (nullable) |
| `published_date` | timestamp | Date the article was originally published |
| `published_date_confidence` | float | Confidence score (0–1) for the inferred published date |
| `title` | text | Article title |
| `summary` | text | AI-generated summary of the article (via OpenAI `gpt-4o-mini`) |
| `article_hash` | int | Hash of the archive URL — used as the image filename (e.g. `{article_hash}.png`) |
| `link_to_archive` | text | Full Arquivo.pt archive URL |
| `link_to_archive_trimmed` | text | Normalised archive URL used for deduplication |
| `link_to_archive_image` | text | URL to the Arquivo.pt screenshot of the article |
| `original_image_path` | text | Local path to the full-size screenshot (PNG) |
| `small_image_path` | text | Local path to the thumbnail screenshot (PNG) |

---

### `article_chunk_medium.parquet`

One row per text chunk of an article. Each article is split into overlapping chunks for semantic search. The `tsv` (PostgreSQL full-text search) generated column is omitted.

| Column | Type | Description |
|---|---|---|
| `id` | int | Primary key |
| `article_id` | int | Foreign key → `article.id` |
| `chunk_index` | int | Zero-based position of this chunk within the article |
| `content` | text | Raw text content of the chunk |
| `embedding` | text | OpenAI `text-embedding-3-large` vector (2000 dims), serialised as a string `[f1,f2,...]`. Nullable — may be absent if only Cohere embeddings were generated. |
| `embedding_cohere` | text | Cohere `embed-multilingual-v3.0` vector (1024 dims), serialised as a string `[f1,f2,...]`. Nullable. |

#### Parsing embeddings

The vector columns are exported as strings. To convert them back to float arrays in Python:

```python
import ast
import numpy as np

df["embedding_cohere"] = df["embedding_cohere"].apply(
    lambda x: np.array(ast.literal_eval(x), dtype=np.float32) if x else None
)
```

## Notes

- Only articles that passed the full processing pipeline are included: image validity check → OCR → AI summarisation → embedding generation.
- Articles about **Portuguese politicians** (ministers, party leaders, parliament members, and presidential candidates) from 1974 to present are the primary subject matter.
- News sources are Portuguese outlets archived by [Arquivo.pt](https://arquivo.pt).
